# ポケットモンスター エメラルド（日本語版）

Pokémon Emerald 3Ds Dual Screen は、日本版 **ポケットモンスター エメラルド
（BPEJ）** のクリーンな ROM でも遊べます。テキストとグラフィックはあなた自身の
ROM から作られ、配布はされません。生成はあなたのパソコンかブラウザの中で行われます。

**ステータス：実験的。** 実機（3DS）でのテストはまだ行われていません。

## インストール

英語版と同じです。ウェブ版と Windows 版のビルダーはどの ROM も受け付け、言語を
ROM から自動で選びます。各リリースには英語版・スペイン語版・日本語版の実行ファイルが、
それぞれのレシピと一緒に含まれます。クイックアップデート（3DSX のみ）では、ウェブが
`emerald3ds.pak` を確認して `Emerald3DS-ja.3dsx` を案内します。SD カードには
`Emerald3DS.3dsx` として保存されます。

| 言語 | コード | クリーンな ROM の SHA-1 |
|---|---|---|
| 日本語 | BPEJ | `d7cf8f156ba9c455d164e1ea780a6bf1945465c2` |
| 英語 | BPEE | `f3ae088181bf583e55daf962a92bb46f4f1d07b7` |

## ソースからビルドする

[開発ガイド](DEVELOPMENT.md)の環境で：

```sh
python tools/bootstrap.py --make --japanese-rom "/path/Pocket Monsters - Emerald (Japan).gba" -j8
```

bootstrap はパッチを当て、ツールと生成インクルードをビルドし、あなたの ROM で
`tools/localize_japanese.py` を実行してから、3DSX を
`build/upstream/3ds_port/emerald3ds.3dsx` にビルドします。言語を切り替えると
（`--japanese-rom` なしで再実行するなど）、ツリーはリセットされ、ビルド済みの
オブジェクトとローカライズしたデータは削除されます。他の言語のデータを使い回さない
ためです。

エンジンはビルドされた言語を確認します。日本語版の実行ファイルは BPEJ から作られた
データパックしか受け付けません。

## 日本語版の仕組み

`tools/localize_japanese.py` は、ツリーに書き込む前に ROM の SHA-1 とソース
ファイルの SHA-256 を確認します。`tools/locales/japanese.json.gz` と
`japanese-symbols.s.gz` に含まれるのは、ソース上の位置、ROM 上のオフセットと
サイズ、シンボル名とアドレスだけです。テキスト、グラフィック、サウンド、ROM の
一部は含まれません。

置き換えるソース上の範囲はスペイン語版のマニフェストと共通なので、日本語版も同じ
範囲をカバーします：名前、会話、メニュー、かんたんかいわの単語、トレーナーの台詞、
メール、テレビ、遺跡の点字など。そのほかに：

- 140 以上のグラフィック（メニュー、バトル、ずかん、ポケナビ、名前入力など）、
  日本語フォント、日本版で異なる 5 つのマップとタイルセット。
- 日本語のスタッフロール（45 ページ）。
- タッチスクリーンの日本語ラベル、ずかんのメートルとキログラム表示。

日本語のパッチ（`patches/pokeemerald/0041-…`、`0042-…`、すべて `PORT_BRIDGE`
内）：

- `0041`：テキストをゲームの日本語グリフで描く。
- `0042`：名前入力のキーボードを日本版の配列（ひらがな・カタカナ・英数）にし、
  押したキーに表示されている文字を入力する。名前は日本版と同じく 5 文字まで。

`0035`（ずかんのメートル法）と `0040`（トレーナーヒルのフロア）は日本語版にも
適用されます。

ポートの変更でマニフェストが参照するファイルが変わると、ローカライズは停止します
（「Source differs from the pinned patched tree」）。その場合は
`tools/locale_research/rebase_manifest.py` で両方のマニフェストを新しいツリーに
移します（ROM は不要です）。

## マニフェストの生成

スペイン語版の生成ツールは公開されていませんでした。日本語版のツールは
`tools/locale_research/` にあります：

```sh
pip install -r tools/requirements-research.txt
python tools/locale_research/make_japanese_manifest.py \
    --elf pokeemerald.elf --english-rom baserom.gba \
    --japanese-rom "Pocket Monsters - Emerald (Japan).gba" --tree build/upstream \
    --report japanese-unmapped.txt
```

`--elf` は固定された upstream を agbcc でビルドし（`make compare`）、
`--emit-relocs` でリンクした英語版の ELF です。`match_rom.py` はそのリロケーション
（ROM 内のすべてのポインタと関数呼び出し）を使い、英語版の各オブジェクトを日本版の
ROM から探します。リロケーションをマスクしたコード比較、ポインタの伝播、隣り合う
オブジェクト間のアラインメント、日本版でレイアウトの異なるテーブル（固定幅の文字列、
サイズの違う構造体、ポインタではなく並べて置かれた文字列）、書き換えられた関数の
リテラルプール、隣り合う文字列の並び順を使います。結果は、文字列の並び順と、
英語版と日本版のプレースホルダー（`{PLAYER}` など）の一致でも検証しています。

## 制限事項

- 英語版にしかないテキスト（約 370 箇所、`--report` の一覧）は英語のままです。
  英字と数字は日本語フォントでも読めます（全角で表示されます）。
- タイトル画面のロゴは英語版のままです（日本版のロゴは、書き換えられたタイトル
  画面のコードで配置されています）。
- トレーナーヒルのフロアは英語版のものです（日本版はチャレンジが 1 つしかなく、
  データの構造も異なります）。
- かんたんかいわの単語一覧の「あいうえお順」はまだ英語版のアルファベット順です。
- 翻訳の後に追加された機能の一部（ポケナビのヘルプのタッチ位置など）は英語の
  レイアウトのままの可能性があります。
